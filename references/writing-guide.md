# 听稿写作指南 —— 给耳朵写，不是给眼睛写

这份指南解决「从源文档到听稿」那一步的判断。格式（`@@编号|标题`、空行分段）见
README 第三节；这里只讲**正文怎么写**。规则来自两个前身的真实返工记录：v1
（`article-to-audio`）的 text-conversion 规则表，和 v2（`md2audio`）的听稿纪律。
标了「实测」的条目有测量依据，其余是经验规则。

## 0. 核心区别

| 给眼睛看 | 给耳朵听 | 由此产生的失败 |
|---|---|---|
| 可以回头查 | 听过去就没了 | 信息密度不能高于一次通过的上限 |
| 可以扫表格 | 只能线性听 | 表格直接念 = 念经 |
| 可以重读数字 | 数字只有一次机会 | 数字错了听众无法察觉 |
| 可以跳过引用 | 引用是强制的时间税 | 一条 URL ≈ 15 秒噪声 |
| 可以看图 | 图不存在 | 图里的结论丢了 |

**任何迫使听众倒回去重听的东西都是 bug，不是风格选择。**

## 1. 结构：开场给地图，每节有小结，结尾给清单

- 开场一节说清楚「接下来几段、分别讲什么」。
- **每节结尾两三句小结**。八节就是八次「刚才说到哪儿了」的重置，长内容才听得完。
- 最后一节把该记的东西按重要性列一遍。
- 一节一个主题。章节也是合成的断点单位：断线重试只损失一章（`--resume`），
  所以长稿宁可多拆章。

## 2. 表格 → 固定顺序的散文

单条影响最大的规则。逐格念表格是灾难。

原文：

```
| 年度 | 预测净利润 | 对应 PE |
| 2026E | 72.2 亿 | 约 57 倍 |
| 2027E | 103.9 亿 | 约 40 倍 |
```

听稿：「二零二六年，预测净利润七十二点二亿，按现价对应约五十七倍市盈率。
二零二七年，一百零三点九亿，对应约四十倍。」

要点：

- **表头的限定语必须进句子**。「按现价对应」是表格借列名暗示的免责，
  丢了它数字就是误导。
- 顺序固定比顺序「合理」更重要：*这是什么 → 证据数字 → 机制 → 对结论是
  打折还是成立 → 怎么自测 → 什么时候停*。列序怎么换都听得懂，
  是因为念的顺序永远一样。

## 3. 图表：先读，再念成句子

研究报告里，图经常**就是**结论本身；只念周围的文字 = 留下主张、丢掉证据。

- 每张图：把轴标签和数值按顺序写成句子，放在图原来的位置。
- **图上印的警告是内容**。一张图标着「各来源成本口径不同、不可直接比较」——
  这句必须进听稿，它是「一个数字」和「一个误导性数字」的差别。
- **「几个没过线」的框架**。五根柱子对一条基线，重点通常是「五分之四没有
  跑赢」；只念五个数、不数这个数，等于把图的白念了。
- 看不到的图（损坏、格式打不开）要**声明**而不是静默跳过：
  「报告此处有一张图，我看不到，请你回去看原文。」

## 4. 缩写三分法

逐个术语判断，不要一刀切。**判据：念出这几个字母，听众能否解码出意义。**

| 处理 | 例子 | 理由 |
|---|---|---|
| **展开** | `PE`→市盈率、`ROE`→净资产收益率、`EPS`→每股收益、`DCF`→现金流折现、`MCU`→微控制器 | 念字母串零信息量 |
| **保留 + 首次注解** | `ETF`、`NVDA`、`TalkBack`、`iFinD` | 本身是可念的名字，名字就是标识 |
| **换成意思** | `alt／label`→替代文字或标签、`vibe coding`→AI 辅助写程序 | 对听众零信息 |

首次出现注解一次，之后只用短名。一节课里短名别超过三四个。

**公司代码和短代号是信息，不许静默删。** 原文说「DA 與 RBV 差距」，改写成
「兩家公司」是丢信息。要么念得出来，要么在随附的对照稿里保留原样——
映射关系不能断。静默删除一个名称，是本工具明令禁止的失败模式。

## 5. 界面功能名的中英处理

技术专名保留；界面功能名翻译——听众要的是功能，不是设置菜单里的字符串。

- `Liquid Glass` → 保留（设计语言，人人都懂）
- `Reduce Motion` → 減少動態效果（首次注解英文，之后只用中文）
- `Live Captions` → 現場字幕（Live Captions）

## 6. 数字怎么写（本节与验证引擎直接相关）

**整数写中文，小数和量级敏感数写阿拉伯。** 这是实测的折中（whisper 会把中文
数字还原成阿拉伯数字，所以两种写法都能验证）：

| 写法 | 问题 | 改成 |
|---|---|---|
| `二点五倍` | 中文小数容易丢小数点 | `2.5 倍` |
| `三百万亿` | 量级歧义：字面是 3×10¹⁴，说话人多半指 3×10¹¹ | `三千億` 或 `3000 億` |
| `25%` | 不少引擎会逐字符念，节奏全毁 | `百分之二十五` |

带方向的符号要落成词：`+1.79%` → 「上漲百分之一點七九」；`-5.4pct` →
「下滑五點四個百分點」（`pct` 不是听众能解码的单位）。

范围要把边界念全：`+12%～15%` → 「成長百分之十二到百分之十五」，
否则第二个数听着像另一件事。

**写完跑一次体检**（不花钱、不联网）：

```bash
python -m a2a keys 听稿.txt --lint
```

它会列出所有中文小数、中文大数和量级歧义写法，逐条给出建议改法
（歧义的除外——工具不知道你指哪个量级，只能让你重写）。

型号里的数字（`MI355X` 的 355、`H100` 的 100）**不用改也不用管验证**：
自动挑键时会剔除它们，那是型号不是数据。

## 7. 标点

- `——` 改句号。引擎会一口气连读不换气，出来一整句 run-on。
  只在真正的插入语处保留。
- markdown 标记（`**`、`#`、`[]()`）属于源文档，不属于听稿。听稿是纯文本，
  标记会被按字面处理。链接剥掉，标题落成话。

## 8. 引用与来源

- 正文里的引用链接全部剥掉。流被打断的地方，与其沉默不如给个路标：
  「細節的部分，這裡就不念了，請你回去看原文。」
- 真正有信息量的来源，放在结尾**口播致谢**（「以上数据主要来自……」），
  不要在正文里逐条念。
- 43 条参考文献念一遍是几分钟的噪声，但**完全不提**也不对——致谢一句即可。

## 9. 剔除元内容，并声明

不是正文的东西：工具的过程日志（「先读取数据插件的使用说明」）、
抛给助手的问题（「要不要我把这段并进清单档」）、导航用的目录页。

- **剔除 + 在听稿开头声明剔了什么**。静默截断原文是歪曲，即使判断是对的。
- **免责声明是内容，不是元信息**（「不构成投资建议」）——保留。
- 推论、外扩、口径换算，显式标记「这是我的推断，不是原文的说法」。
  听的时候没法回看核对来源，这一句标注成本极低、价值极高。
- 诚实限定写在结论**旁边**，不藏进最后一节：样本量、观察期、指标类型——
  「短期生理指标会变好」≠「你会少生病」。

## 10. 哪些仍是判断，不是规则

一段话是内容还是元信息，密度多高算「听得完」，摘要砍到多细——这些无法规则化。
本指南消除的是**已知必坏**的写法；听众到底需要什么，值得你逐篇过一遍。
这一步是整个流水线里质量的上限，也是它最花时间的地方。
